ENGEL-2

SORUN:

Sysmon üzerinde oluşturulan `sysmon-test.txt` dosyasının Event ID 11 (File Create) kayıtlarında görünmediği tespit edildi.

HATA MESAJI:

Herhangi bir hata mesajı alınmadı. Dosya sistemde oluşturuldu ancak Sysmon kayıtlarında ilgili dosyaya ait Event ID 11 kaydı bulunamadı.

DENENENLER:

- `sysmon-test.txt` dosyasının sistemde gerçekten oluşturulduğu `dir` komutu ile kontrol edildi.
- Event Viewer üzerinden Sysmon → Operational günlüğünde Event ID 11 kayıtları incelendi.
- PowerShell kullanılarak Event ID 11 kayıtları içerisinde `sysmon-test.txt` arandı.
- Kullanılan `sysmonconfig-export.xml` yapılandırma dosyasındaki `FileCreate` kuralları incelendi.
- Dosya oluşturma olaylarının yapılandırma tarafından filtrelenebildiği görüldü.

ÇÖZÜM:

Herhangi bir sistem hatası bulunmadı. Kullanılan Sysmon yapılandırmasının belirli dosya türlerini ve konumlarını kaydettiği, `.txt` dosyasının ise bu kurallar kapsamında kaydedilmediği belirlendi. Bu durumun Sysmon'un çalışmamasından değil, yapılandırma dosyasındaki filtreleme kurallarından kaynaklandığı tespit edildi.

KAYNAK:

Sysmon `FileCreate` (Event ID 11) ve `sysmonconfig-export.xml` yapılandırma kuralları.
