ENGEL-1

SORUN:

Splunk Enterprise .deb paketiyle kurulduktan sonra, servisi başlatmak için çalıştırılan sudo /opt/splunk/bin/splunk start --accept-license komutu lisans kabulü ve admin kullanıcı adı/şifre oluşturma adımlarını tamamladı ancak splunkd servisi başlatılamadı.

HATA MESAJI:

splunkd is not running.

DENENENLER:

sudo /opt/splunk/bin/splunk status ile servis durumu kontrol edildi.
sudo tail -n 50 /opt/splunk/var/log/splunk/splunkd.log ile log dosyası incelenmeye çalışıldı, dosyanın hiç oluşmadığı görüldü.
sudo ls -la /opt/splunk/var/log/splunk/ ile log klasörü kontrol edildi, yalnızca btool.log ve first_install.log dosyalarının bulunduğu, splunkd.log dosyasının hiç oluşmadığı doğrulandı.
first_install.log içeriği incelendi, sadece sürüm bilgisi (VERSION, BUILD, PLATFORM) bulunduğu, hataya dair bir ipucu içermediği görüldü.
Kurulum sırasında çıkan "Running Splunk Enterprise as root is deprecated and will be removed in a future release. For details, see the Release Notes. To run as root, use the --run-as-root option." uyarısı tekrar incelendi.

ÇÖZÜM:

Splunk'ın .deb paketiyle sudo dpkg -i komutuyla, yani root yetkisiyle kurulmuş olması ile servisin normal başlatma komutuyla ayağa kaldırılmaya çalışılması arasında bir dosya sahiplik/izin uyumsuzluğu olduğu değerlendirildi. Komut --run-as-root parametresi eklenerek tekrar çalıştırıldı:

sudo /opt/splunk/bin/splunk start --accept-license --run-as-root

Bu çalıştırmada tüm ön kontroller (port kontrolü, sertifika oluşturma, index doğrulama, dosya sistemi uyumluluğu) başarıyla tamamlandı ve splunkd servisi başarıyla başlatıldı. Web arayüzüne http://localhost:8000 üzerinden admin bilgileriyle giriş yapılarak kurulumun çalıştığı doğrulandı.

KAYNAK:

Splunk kurulum çıktısındaki "Running Splunk Enterprise as root is deprecated" uyarısı ve --run-as-root başlatma parametresi.
