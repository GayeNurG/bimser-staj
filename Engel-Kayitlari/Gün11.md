ENGEL-1

SORUN:

Nginx servisi üzerinde systemctl komutları kullanılırken servis yapılandırma dosyasının değiştiğini belirten bir uyarı görüntülendi.

HATA MESAJI:

Warning: The unit file, source configuration file or drop-ins of nginx.service changed on disk. Run 'systemctl daemon-reload' to reload units.

DENENENLER:

Nginx servisinin mevcut durumu systemctl status nginx komutu ile kontrol edildi.
Servis yapılandırmasının systemd tarafından yeniden okunması gerektiği değerlendirildi.
sudo systemctl daemon-reload komutu uygulandı.
Ardından Nginx servisi tekrar kontrol edildi.

ÇÖZÜM:

sudo systemctl daemon-reload komutu ile systemd'nin servis yapılandırmasını yeniden okuması sağlandı. Sonrasında Nginx servisi sudo systemctl start nginx komutu ile başlatıldı ve active (running) durumuna geldi.

KAYNAK:

systemctl ve systemd servis yönetimi.
